# HireSync 로드맵 제안

[메인 README](../../README.md)

저장소의 백엔드 Gradle 버전은 **0.0.1-SNAPSHOT**, 프런트엔드 package 버전은 **0.1.0**입니다. 아래 버전은 제품 릴리스 태그가 아니라 계획을 정리하기 위한 제안이며 실제 버전을 정할 때 백엔드·프런트엔드 표기도 함께 맞춰야 합니다.

## 다음 마일스톤 제안 — v0.2.0: 안전한 공고 수집·관리

- PDF 및 URL 추출 결과의 필드별 검증과 사용자 수정 흐름 보강
- 공고 출처·수집 시각·원문 링크·마감일 신뢰도 관리
- 로컬 H2에서 운영 DB로 전환하고 스키마 마이그레이션 도입
- 테스트 계정과 초기 관리자 생성 정책 분리
- 백엔드 API 테스트를 CI에 포함하고 배포 전 빌드 검증

## 이후 후보 — v0.3.0: 운영자 워크플로

- 공고 승인·반려 이력과 처리 사유
- 사용자별 권한 및 관리 작업 감사 로그 강화
- 채용 사이트별 수집기 오류 감지 및 재시도
- 업로드 문서의 보관·삭제 정책과 개인정보 처리 UX

## 배포 상태

현재 저장소에는 CD나 클라우드 배포 설정이 확인되지 않습니다. 운영 환경을 계획할 때 배포 플랫폼, DB, 파일 저장소, 메일 서비스, 비밀값 관리 방식을 먼저 결정하고 운영 계정·접근제어를 검증해야 합니다.
