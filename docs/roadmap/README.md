# 로드맵 및 버전

## 현재 버전 근거

백엔드와 프런트엔드가 별도 버전을 선언합니다.

| 모듈 | 설정 파일의 버전 |
| --- | --- |
| 백엔드 | `backend/build.gradle`: `0.0.1-SNAPSHOT` |
| 프런트엔드 | `frontend/package.json`: `0.1.0` |

`changelog.md`의 가장 최근 항목은 `1.0.2`이지만 Gradle·npm 버전과 일치하지 않습니다. 이를 현재 통합 릴리스 버전으로 볼 근거는 확인되지 않았습니다. Git 태그와 다음 릴리스 버전·일정도 확인되지 않았습니다.

## 계획 항목과 확정 릴리스 구분

**확정 릴리스:** 다음 버전 번호나 출시일이 정해진 계획은 저장소에서 찾지 못했습니다.

**계획 문서에 등장하는 항목 (출시 약속 아님):**

- `specs/001-job-info-service/spec.md`에는 이메일 채용 정보 등록 시나리오가 있습니다. `EmailService`에 이메일 본문 처리 로직은 있지만 수신을 시작하는 메일 리스너나 컨트롤러는 확인되지 않아 전체 흐름은 **확인 필요**입니다.
- `specs/001-job-info-service/tasks.md`와 관련 명세에는 공고·추출·API 구현 작업 목록이 있습니다. 현재 코드와 겹치는 내용이 있어 문서만으로 미완료 여부를 판단하지 않습니다.

새 기능의 우선순위, 담당자, 릴리스 버전과 일정은 별도로 확정해야 합니다. 위 항목은 계획 문서의 기록이며 제공 일정이 아닙니다.
