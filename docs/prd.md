# 요구사항

1. 기능적 요구사항 (Functional Requirements)
사용자 역할(개인 구직자, 기업 담당자, 관리자)에 따라 필요한 핵심 기능입니다..

👤 개인 구직자 (Job Seeker)
회원가입/로그인: 소셜 로그인(Google, Kakao), 이메일 인증.

프로필 및 이력서 관리: PDF 업로드, 웹 내 이력서 작성, 기술 스택 태그 관리.

채용 공고 검색: 직군, 지역, 경력, 연봉 등 필터 검색.

지원 및 상태 추적: 지원 완료, 서류 합격, 면접 일정, 결과 확인 프로세스.

맞춤형 알림: 관심 기업의 새 공고나 매칭되는 공고 push/메일 알림.

🏢 기업 담당자 (Employer)
공고 관리: 채용 공고 등록, 수정, 마감 관리.

지원자 관리: 지원 현황 대시보드, 이력서 검토, 합격/불합격 통보 발송.

기업 페이지: 회사 소개, 복지, 조직 문화, 재무 정보 등록.

🛠 관리자 (Admin)
콘텐츠 검수: 부적절한 공고나 허위 이력서 필터링 및 차단.

통계 분석: 가입자 수, 공고 등록 수, 매칭 성공률 등 데이터 시각화.

2. 비기능적 요구사항 (Non-functional Requirements)
시스템이 얼마나 잘 작동해야 하는지에 대한 품질 기준입니다.

성능(Performance): 메인 페이지 로딩 속도는 2초 이내여야 함.

보안(Security): 개인정보(전화번호, 주소 등)는 암호화하여 저장하며, HTTPS 프로토콜 사용.

가용성(Availability): 연중무휴 99.9% 이상의 서비스 가동률 유지.

확장성(Scalability): 클라우드 기반(AWS 등)으로 트래픽 급증 시 서버 자원 자동 확장(Auto-scaling).

반응형 디자인: PC, 태블릿, 모바일 등 모든 기기에서 최적화된 UI 제공.

3. 차별화 포인트 (Project Plus)
단순한 게시판 형태를 넘어, 본인의 기술력을 보여줄 수 있는 기능입니다.

AI 매칭 시스템: 구직자의 기술 스택과 기업의 요구사항을 분석하여 적합도를 %로 표시 (현재 진행 중인 AI 프로젝트 경험 활용).

포트폴리오 클라우드 백업: 이력서 외에 개발 결과물이나 증빙 서류를 안전하게 저장하는 기능 (기존 '개인 학습 데이터 백업' 아이디어 응용).

실시간 채팅/Q&A: 기업 담당자와 구직자 간의 실시간 문의 기능.
